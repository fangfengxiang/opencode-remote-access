# Community and related projects

[简体中文](../community.md) · **English**

| Project | Primary use |
| --- | --- |
| [Open Remote Control](https://github.com/lesquel/open-remote-control) | The closest plugin. It provides a mobile dashboard, QR pairing, tunneling, and Telegram control. |
| [OpenChamber](https://github.com/openchamber/openchamber) | A standalone OpenCode workspace with remote instances and device pairing. |
| [OpenCode Web](https://opencode.ai/docs/cli/web) | The built-in browser interface. This plugin configures a gateway to that interface from Desktop settings. |

The project combines native OpenCode Desktop settings with the existing OpenCode Web interface and controls for HTTPS, source IP allowlists, and sign-in logs.

- Share an introduction and request feedback in the Plugin category of [awesome-opencode Discussions](https://github.com/awesome-opencode/awesome-opencode/discussions).
- Share a screenshot and demo on the [official OpenCode Discord](https://opencode.ai/discord) according to the channel rules.
- The [OpenCode Ecosystem](https://opencode.ai/docs/ecosystem/) page invites pull requests. It currently points to V1 documentation, so identify the V2 GUI plugin requirement in a submission.
- [r/opencodeCLI](https://www.reddit.com/r/opencodeCLI/) has community plugin announcements. Check its posting rules before sharing.

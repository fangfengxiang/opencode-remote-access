# 社区与相关项目

**简体中文** · [English](en/community.md)

| 项目 | 主要用途 |
| --- | --- |
| [Open Remote Control](https://github.com/lesquel/open-remote-control) | 最接近的插件。提供移动网页仪表板、二维码、隧道和 Telegram 控制。 |
| [OpenChamber](https://github.com/openchamber/openchamber) | 独立的 OpenCode 工作区，支持远程实例和设备配对。 |
| [OpenCode Web](https://opencode.ai/docs/cli/web) | OpenCode 自带的浏览器界面。本插件通过桌面设置配置提供该界面的远程网关。 |

本项目的发布重点是 OpenCode Desktop 原生设置、沿用 OpenCode Web 界面，以及统一管理 HTTPS、来源白名单和登录日志。

- [awesome-opencode Discussions](https://github.com/awesome-opencode/awesome-opencode/discussions) 的 Plugin 分类适合发布介绍并收集反馈。
- [OpenCode 官方 Discord](https://opencode.ai/discord) 适合分享带截图的演示，发帖前查看频道规则。
- [OpenCode Ecosystem](https://opencode.ai/docs/ecosystem/) 的页面接受 PR。该链接目前指向 V1 文档，提交时应注明本插件依赖 V2 GUI 插件接口。
- [r/opencodeCLI](https://www.reddit.com/r/opencodeCLI/) 有社区插件发布实例，可按版规发帖。

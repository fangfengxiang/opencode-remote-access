# 功能说明

**简体中文** · [English](features.en.md)

| 功能 | 使用方式 |
| --- | --- |
| 原生设置页 | **设置 → 远程访问**。跟随桌面端语言，支持简体中文、繁體中文、English 和 Русский。 |
| 远程监听 | 选择本机 IPv4 地址和与本机 OpenCode 服务不同的端口。启用 HTTPS 时可自动生成自签名证书，或选择已有的 PEM 证书和私钥。 |
| 远程登录 | 设置远程用户名和密码。密码默认遮挡，可用眼睛按钮查看。 |
| 配置生效 | **保存**仅写入待应用配置。**保存并重启**立即重建远程监听，失败时尝试恢复原监听。 |
| 浏览器自动登录 | **在浏览器中打开**生成并打开临时配对链接，浏览器兑换后登录。 |
| 一次性配对 | 提供标准 URL 二维码、OpenCode App 二维码和配对链接。五分钟到期后遮蔽二维码并划去链接。 |
| 来源限制 | 白名单支持单个 IP 和 CIDR 网段。用实际套接字来源判定，拦截结果写入登录日志。 |
| 当前连接 | 显示来源 IP、可用的设备信息和 TCP 连接数。可管理设备别名。 |
| 登录日志 | 保留最近 500 条，支持查看、调整文件路径、打开、停用记录和清空。空日志禁用查看、打开和清空按钮。 |
| 终端控制 | macOS 和 Linux 可通过 `oc-listen`、`oc-qr` 控制同一远程入口。 |

调整托管监听会断开当前远程连接，先前配对的设备需要重新登录或配对。未配置白名单时允许任意来源。同机浏览器也按白名单校验。

## 平台

- macOS 上验证了 OpenCode Desktop v2.3.0。
- Ubuntu 24.04.5 LTS 容器使用 Node.js 18.19.1 和 OpenSSL 3.0.13，通过 TLS、配对、WebSocket、白名单、日志及主进程测试。Ubuntu 的桌面 GUI 未实测。
- Windows 提供官方 OpenCode Desktop 构建。桌面功能使用跨平台的 Electron 和 Node.js 接口，尚未在 Windows 桌面实机验收。
- 可选终端命令使用 Unix 套接字。Windows 开启监听和生成二维码使用桌面设置。
- 自动生成 HTTPS 证书需要 PATH 中的 OpenSSL。自备 PEM 证书由 Node.js 加载。

# 支持的功能

| 功能 | 使用方式 |
| --- | --- |
| 桌面端设置 | 在 OpenCode 的 **设置 → 远程访问**中查看和修改。 |
| 自定义监听 | 绑定本机所拥有的 IPv4 地址和用户设置的远程端口。远程端口与 OpenCode 本机服务端口分开，适用于 Tailscale 或其他可达的本机网络地址。 |
| 自定义登录 | 使用自己设置的远程用户名和密码。密码默认遮挡，可用眼睛按钮查看。 |
| 生效与恢复 | 监听运行期间保存新配置会重启远程入口。新监听启动失败时，插件会尝试恢复原配置。 |
| 浏览器测试 | 启动后可打开当前 HTTP URL。 |
| 一次性配对 | 生成 OpenCode 配对二维码和链接。 |
| 当前连接 | 按 TCP 来源 IP 显示当前连接数，连接断开后更新。 |
| 配置文件 | 地址、端口、账号和密码存放在用户目录下的 `~/.opencode/remote.json`。 |
| 命令行控制 | `oc-listen` 和 `oc-qr` 通过桌面插件操作同一个入口。关闭桌面端会停止插件监听。 |

当前连接数统计已接入的 TCP 连接，包括打开浏览器等操作产生的连接。断开后从列表移除，计数随监听结束清理。登录结果由各客户端在建立应用会话时反馈。

保存变更会关闭旧的远程连接。修改后，已有远程设备需要使用当前凭据登录或重新配对。

## 设置页与日志

- 设置页使用 OpenCode 的原生输入框、按钮、开关与设置分区，通过宿主语言实时切换简体中文和英文。
- **保存**只写配置。**保存并重启**重建远程监听，期间显示「重启中」。已保存的改动等待应用时，监听区提供提示。
- 相机模式提供标准 URL 二维码。App 模式提供 OpenCode 原生配对二维码。到期后覆盖二维码并划掉链接。
- 支持按设备标识显示当前连接、为设备设置及删除别名，以及标记本机流量。
- 登录日志默认保留最近 500 条，支持查看、打开文件、切换记录、清空与修改绝对路径。关闭记录可保留现有日志。

- 来源 IP 白名单支持指定 IP 和 CIDR 网段。规则使用实际 TCP 来源，拦截结果写入日志。

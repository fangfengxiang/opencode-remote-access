# 设计文档

## 桌面组件和本机服务

插件通过 OpenCode 的 GUI 插件入口加载。窗口使用 OpenCode 原生设置组件，Electron 主进程负责读写配置、管理监听、签发远程会话和打开浏览器。窗口通过插件 IPC 接收当前监听 URL 和来源 IP 计数。

插件从桌面端提供的本机服务信息取得上游地址及认证头。上游服务地址随 OpenCode 安装和配置确定。插件在保存或启动前对照上游端口校验远程端口，发现冲突时保留原设置并提示选择其他端口。外部监听地址、端口、账号和密码由用户配置，保存在 `~/.opencode/remote.json` 中。

## 远程请求

远程入口在指定的本机接口上接受 HTTP 请求。在转发前验证用户提供的远程凭据或插件签发的会话，然后使用桌面端提供的认证信息调用上游。上游认证信息只在本机进程使用。

配对在 OpenCode 本机服务生成一次性链接。远程设备兑换配对码后，插件签发远程会话，供浏览器或远程 OpenCode 客户端使用。每次重建监听会话时会重新生成签发信息，旧会话随旧监听一起失效。

监听关闭时清理该监听的 TCP 连接及计数。来源地址来自接入套接字，统计数据保存在当前进程内存中。

## 配置和生命周期

监听和配置操作在主进程中串行执行。配置文件采用临时文件写入后替换的方式，并使用用户专用权限。保存配置时，如果监听正在运行，插件会以新配置重建监听。如果启动或写入失败，会尝试恢复原监听。账号密码通过重建远程入口生效。

可选的终端快捷命令通过当前用户的本地 Unix 套接字调用桌面插件。应用退出后，远程入口和本地控制入口随之关闭。

## 发布产物

`src/` 保留手写 CommonJS 源码。`node scripts/build.cjs` 生成根目录下的 `gui-experimental.cjs`，由 `package.json` 的 `./gui-experimental` 导出。构建仅使用 Node.js 内置模块。用户通过 `opencode plugin add` 注册 GitHub 包时，OpenCode 直接加载仓库自带的生成文件。`node scripts/build.cjs --check` 可校验生成文件与源码一致。
